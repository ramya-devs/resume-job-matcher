# 📄 Resume → Job Match Analyzer

An NLP-powered web application that analyzes how well a resume matches a job description using semantic similarity, skill analysis, experience matching, and ATS-style compatibility analysis.

## 📌 Overview

Finding out whether a resume matches a particular job description can be difficult.

The **Resume → Job Match Analyzer** helps job seekers understand how closely their resume aligns with a target role.

Users can upload a resume, paste a job description, and receive an analysis containing:

- 🎯 Resume–Job Match Score
- 🧠 Semantic Similarity
- 🛠️ Matched Skills
- ❌ Missing Skills
- 🔎 Skill Evidence
- 💼 Experience Match
- 🤖 ATS Compatibility Analysis
- 📈 Required Skill Coverage
- 💡 Personalized Improvement Suggestions
- 📥 Downloadable PDF Analysis Report
